> A cross-platform mobile companion engineered with Expo & React Native to support preventive breast health monitoring, structured self-exam guidance, and personalized risk assessment workflows.

---

## 🌟 Key Features

- **Guided Self-Exam Engine**: Visual step-by-step guidance designed to promote consistent monthly checks.
- **Symptom & Observation Tracker**: Time-series recording with secure photo capture and local encryption.
- **Health Telemetry & Reminders**: Native push notifications timed to hormonal cycles.
- **Educational Knowledge Base**: Medically vetted FAQs and screening milestone checklists.

---

## 📱 Tech Stack & Architecture

- **Client**: Expo Go / React Native (iOS & Android universal build)
- **Navigation**: React Navigation (Native Stack + Tab Navigators)
- **Backend & Storage**: Firebase Firestore, Firebase Storage & Authentication
- **Local Cache**: AsyncStorage with encrypted persistence

---

## 🚀 Running Locally

```bash
git clone https://github.com/Jawknee-builds/rosette.git
cd rosette

npm install
npx expo start
```
Scan the QR code with Expo Go (Android) or the Camera app (iOS).
